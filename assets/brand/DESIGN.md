# 히썹 디자인 기준 (DESIGN.md)

디자인 담당(차은우)이 **그리기 전에 매번 읽는** 기준입니다. 내부 검수(박서준)도 이걸로 봅니다.
원장님이 "항상 이렇게" 라고 한 것은 여기에 적어서, 같은 말을 두 번 하지 않게 합니다.
(형식은 VoltAgent/awesome-design-md 를 따랐습니다.)

## 1. 한눈에

반영구 교육과 시술을 하는 원장님의 계정입니다. **깨끗하고 단정하며, 주황 한 색으로 기억되는** 화면.
화려한 장식보다 큰 글씨 한 줄과 넉넉한 여백. 전문가가 만든 인쇄물처럼, AI 가 만든 티가 나지 않게.

## 2. 색

| 이름 | 값 | 쓰임 |
|---|---|---|
| 시그니처 주황 | `#FA5500` | 라벨, 강조 단어, 포인트 띠, 숫자. **강조는 늘 주황** |
| 밝은 주황 | `#FF7A47` | 주황 위 그라데이션이나 보조 강조 |
| 잉크 | `#0A0A0A` | 본문과 제목 글자 |
| 종이 | `#FFFFFF` | 기본 배경 |
| 크림 | `#FAF8F5` | 부드러운 배경 |
| 흐린 글자 | `rgba(10,10,10,0.5)` | 보조 설명, 계정 표시 |
| 별 노랑 | `#FFC83D` | 후기 별점에만 |

- 원장님: "시그니처컬러는 항상 주황". 강조색을 다른 색(분홍, 보라, 파랑)으로 바꾸지 않습니다.
- 한 장에 주황은 많아야 두세 군데. 다 주황이면 아무것도 안 보입니다.
- 어두운 배경을 쓸 때는 잉크(거의 검정)나 짙은 브라운. 흰 배경도 좋습니다.

## 3. 글꼴

- 기본은 **Pretendard** (400, 500, 600, 700, 800).
- 제목: 800, 자간 -0.02em ~ -0.035em, 줄간격 1.05~1.15. 크고 짧게.
- 본문: 500~600, 줄간격 1.3~1.45.
- 라벨(영문 대문자): 800, 자간 0.15~0.22em.
- 1080px 카드에서 읽으라고 넣은 글자는 **28px 아래로 내리지 않습니다**.
- 한글은 `word-break: keep-all`. 단어 중간에서 줄이 나뉘면 안 됩니다.

## 4. 배치

- 캔버스 1080×1350 (인스타 세로 4:5). 영상은 1080×1920.
- 바깥 여백: 좌우 64~84px, 위 56~72px, 아래 68~80px.
- 간격 단위 8px (8, 16, 24, 32, 48, 64).
- 가장 중요한 말이 가장 크게. 위계는 많아야 세 단계(제목, 본문, 보조).

## 5. 로고

- 아카데미 계정: `HSSUP ACADEMY` 로고. 아트메이크 계정: `HSSUP` 로고.
- 왼쪽 위, 높이 40~56px. 늘이거나 색을 바꾸지 않습니다(어두운 바탕엔 흰 로고만).
- **로고에 번짐(glow), 흰 그림자, 흐림 효과를 주지 않습니다.** 원장님이 뿌옇다고 하셨습니다.
  밝은 배경 위에서 안 보이면 로고가 아니라 배경을 어둡게(옅은 그라데이션) 합니다.

## 6. 자주 쓰는 조각

- **라벨 띠**: 주황 바탕 + 흰 굵은 영문 대문자. 예: `H-SSUP REVIEW`, `STEP 03`.
- **포인트 막대**: 주황 64×8px, 제목 바로 위.
- **사진 위 글씨**: 아래쪽에 검은 그라데이션(0.85→0)을 깔고 흰 글씨. 그림자는 옅게.
- **후기 카드**: 후기 캡처를 화면 가득 + 아래 그라데이션 + 주황 라벨 + 큰 흰 제목 + 노란 별 다섯 개.
- **이것만 기억하세요**: 주황 선 아래 작은 주황 라벨 + 굵은 한 줄.

## 7. 해도 되는 것 / 하면 안 되는 것

해도 되는 것
- 큰 제목 한 줄과 넉넉한 여백
- 실제 사진(시술, 수업, 후기)을 크게
- 흰 배경, 크림 배경, 아주 어두운 배경

하면 안 되는 것
- 보라색이나 파란색 그라데이션, 유리 효과, 네온 번짐 같은 "AI 가 만든" 티
- 장식이 주인공이 되는 것(단풍잎 가득 같은). 원장님이 단풍을 빼 달라고 하신 적 있습니다
- 로고와 글자에 번짐 효과
- 이모지를 카드 그림 안에 넣는 것 (캡션에는 괜찮음)
- 카드 글을 존댓말로 끝내기 (명사나 단정형으로 끊습니다. 캡션만 예외)
- 글자를 사진 위에 그냥 얹어 안 읽히게 두는 것

## 8. 원장님이 직접 정한 것 (쌓아 갑니다)

- 2026-10-01 "디자인 이런 식으로 해. 시그니처컬러는 항상 주황"
- 2026-10-01 "단풍 빼, 배경은 흰색"
- 2026-10-02 영상 로고가 뿌옇다 → 로고에 번짐 금지
- 후기 게시물은 캔바로 만든 "H-SSUP REVIEW" 디자인을 기준으로 (저장 디자인 「후기」)

## 9. 아직 정해지지 않은 것

- 앱 화면의 주황은 `#FF5C1F`, 게시물의 주황은 `#FA5500` 로 조금 다릅니다. 브랜드 가이드의 정확한 값을 받으면 하나로 맞춥니다.
- 실전 팁 카드뉴스의 강조색이 분홍(`#FF6FA5`)으로 덧씌워져 있습니다(data/hssup-tips-design.css). 위 2번 기준과 어긋나 원장님 확인이 필요합니다.
